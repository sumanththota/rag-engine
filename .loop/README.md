# Feature Loop

Code orchestrates, models work, exit codes decide. The issue body is the contract; the
state file is the state. The implementer never accepts its own work.

- `DESIGN.md` — what v4 is and why
- `RULES.md` — what `drive.sh` enforces, one transition per tick
- `agents/` — planner, implementer, verifier prompts
- `CHECKLIST.md` — what's left before the first run
- `INDEX.md` — ticket history; `<id>/retro.md` per ticket
- `drive.sh` — the orchestrator
